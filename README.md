# Claude AI Improvement

Este repositorio está pensado para documentar, experimentar y mejorar el uso de Claude AI, prompts, workflows y buenas prácticas.

## Objetivo

Centralizar:
- prompts efectivos para distintos casos
- plantillas reutilizables
- documentación de estrategias de prompting
- ejemplos de tareas con Claude
- evaluación de resultados y mejora continua

## Cómo usar este repositorio

1. Revisa la guía de prompting.
2. Usa las plantillas en `prompts/templates/`.
3. Personaliza los ejemplos según tu caso real.
4. Guarda tus mejores prompts para reutilizarlos.
5. Documenta qué funciona y qué no para iterar.

## Plantilla base de prompt

```text
Rol: Eres un experto en [área].
Objetivo: [qué quieres lograr].
Contexto: [situación, repositorio, proyecto, datos].
Restricciones: [límites, estilo, formato].
Tarea: [instrucción clara].
Salida esperada: [formato, estructura].
```

## Buenas prácticas

- Sé específico con el objetivo.
- Proporciona contexto útil y acotado.
- Define formato de salida.
- Pide iteración, revisión o validación cuando haga falta.
- Compara respuestas para mejorar prompts.
- Usa ejemplos concretos cuando la tarea lo requiera.
